## Scope of this delivery

The implemented RFC profile and explicit unsupported cases are documented in the contract package README. This is an experimental development delivery with correctness checks, not a production load or universal calendar-client compatibility certification. Future-series splitting, arbitrary RRULE/VTIMEZONE forms, attendance/scheduling invitations, background push reminders, a dedicated hour-grid layout, single-occurrence snapshot export and automatic publication of legacy migration reports remain separate extensions. Importing ordinary supported ICS files and exporting complete supported series are implemented.

The public HTTPS hostname, final network/account settings and VPS resource allocation are deployment inputs. The existing Nexus instance has not been reconfigured by this implementation. See [deployment.md](deployment.md) before enabling the generic history extension or public calendar subscriptions.
